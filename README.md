# Interactive Calculator & Unit Converter

## Project Description
A beginner-friendly Python command-line application that performs basic arithmetic operations and unit conversions through an interactive menu.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Kilometres to Miles conversion
- Celsius to Fahrenheit conversion
- Kilograms to Pounds conversion
- Input validation using while loops
- Error handling for invalid inputs and division by zero

## Technologies Used
- Python
- VS Code

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

## Unit Conversions
- 1 kilometre = 0.621371 miles
- Fahrenheit = (Celsius × 9/5) + 32
- 1 kilogram = 2.20462 pounds
